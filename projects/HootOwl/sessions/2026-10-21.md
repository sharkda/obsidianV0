## Shipped — C1, the crash fix

`9b957e6` on `main`, pushed. **iOS Debug and Release both `** BUILD SUCCEEDED **`, zero compile errors.** Not yet run on a device or simulator.

Jim's ask: *"I'd want GM 1.0 does not crash, and tell the users if the data update is stalled, I assume we can do this in low hanging fruit, right? if yes, 1.0 and C1 go"* — answered yes, and the second half turned out to be **already built**.

| What | Where |
|---|---|
| Never `fatalError` on a remote payload — 5 sites | `Mu1Base+Ext.swift:222/:225` → new `noteParseFailure()`; `TaipeiObs.swift:91/:94` → `throw`; `TaipeiObs.swift:24` stray one deleted; `NewTaipeiCityObs.swift:137` → `>= 2` |
| Mandatory per-lot surface **4 fields → 2** | `availablemotor` / `availablebus` deleted — non-optional and rendered nowhere |
| A reshaped charger payload costs the badge, not the car count | `ParkAvailableItem.init(from:)`, `ChargeStation` via `try?` |
| One bad lot costs one lot, not ~1,700 | new `LossyArray<T>` |
| A schema break can't masquerade as a partial outage | 70% `decodeFloor`, both cities |
| `UPDATETIME` tolerates two more formats + ISO8601 | `parseUpdateTime`, `en_US` pin kept and documented |

**Three judgement calls inside `noteParseFailure()` worth not undoing:** keep the poll timer running (an early `return` stops the zone forever — quieter than the crash it replaced); publish nothing rather than `nil` (publishing `nil` blanks the map); and **leave `minutelyConfirmedVbj` alone**, or the failure hides behind a fresh-looking timestamp.

> [!success] The "tell the users" half needed no new code
> `StaleDataBanner` already exists, is already wired at `NbsScreen.swift:159`, and already carries both languages: 「最後確認 %@ · 即時更新已中斷」 / *"Last confirmed %@ · live updates have stopped"*.
>
> **It could only ever fire for a network outage.** A feed that answered with something unparseable crashed the app first. C1 is what makes the banner Jim already paid for reachable.

**Proceeded on my own default for J2** (the 70% floor) rather than block on it. It is one constant — `TCMSV_allavailavble.Data.decodeFloor` — and changing it is a one-line edit.
